# Smale's mean value constant exceeds 1.1559 — supporting materials

What is in this folder:

- [lean/](lean/) - the Lean 4 proof of the paper's results. Click it to see the proof and how to check it.
- [pair_checks/](pair_checks/) - the programs that make the four checks of the paper, and their output. Its README says how to run them.
- [pairs/](pairs/) - the exact data of the pair (W, B) that proves the paper's main theorem.
- [figures/](figures/) - the programs that draw Figures 2 and 3 of the paper. The proof does not use them.
- [rebuild_from_printed.py](rebuild_from_printed.py) - checks that the numbers printed in the paper (its LaTeX source) give this data.
