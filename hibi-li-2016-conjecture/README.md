# The Hibi–Li (2016) conjecture is fully resolved — supporting materials

For the paper "The Hibi–Li (2016) conjecture is fully resolved" by Dave Goel. The paper's link will be added here when
it is posted. An expanded version of the paper, with many other results, is on Zenodo:
https://doi.org/10.5281/zenodo.23601975.
